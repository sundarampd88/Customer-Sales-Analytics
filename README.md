# Customer & Sales Analytics

## Project Overview

This project analyzes customer and sales data using Python to understand sales performance, customer behavior, and product-wise sales.

## Objective

The main objective of this project is to clean, analyze, and visualize customer and sales data to generate meaningful business insights.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Analysis Performed

- Data cleaning and preprocessing
- Customer-wise sales analysis
- Product-wise sales analysis
- Total sales calculation
- Data aggregation using Pandas
- Data analysis using NumPy
- Sales data visualization
- Business insights from sales data

## Project Files

- `analysis.ipynb` — Data analysis notebook
- `visualzation.ipynb` — Data visualization notebook
- `graph.py` — Python script for generating graphs
- `cleaned.csv` — Cleaned sales dataset

## Key Skills Demonstrated

- Python programming
- Pandas data manipulation
- NumPy
- Exploratory Data Analysis (EDA)
- Data visualization
- CSV data handling
- Business data analysis

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook or Python script.
4. Run the analysis and visualization.
